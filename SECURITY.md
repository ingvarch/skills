# Security Policy

## Supported versions

Only the latest commit on `main` is supported. Fixes reach users with the next plugin version, see
[Release](docs/development.md#release).

## Report a vulnerability

Report it privately through
[GitHub private vulnerability reporting](https://github.com/ingvarch/skills/security/advisories/new).
Only the maintainer can see the report. Do not open a public issue, pull request or discussion about
it.

Include:

- what an attacker can do and what they need for it: for example, a repository whose content makes
  a skill run a command, leak a secret or change a setting the user did not ask for;
- the steps that show the problem: the skill, the message you typed and the repository state;
- the skill, step or script involved.

The maintainer replies in the advisory, agrees on a fix and a disclosure date with you, and credits
you in the advisory unless you ask not to be named.
