# Security Policy

## Supported versions

<Only the latest release is supported. | Only the latest commit on `main` is supported.> <How a fix
reaches users: the next release, or a deploy of `main` to <URL>.>

## Report a vulnerability

Report it privately through
[GitHub private vulnerability reporting](https://github.com/<owner>/<repo>/security/advisories/new).
Only the maintainer can see the report. Do not open a public issue, pull request or discussion about
it.

Include:

- what an attacker can do and what they need for it;
- the steps that show the problem: <for example, a `curl` command, or the command you ran and its
  input>;
- the <route, command, module or component> involved.

The maintainer replies in the advisory, agrees on a fix and a disclosure date with you, and credits
you in the advisory unless you ask not to be named.
