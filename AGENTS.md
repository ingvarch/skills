# AGENTS.md

This repository is the `ingvarch` Claude Code plugin: skills in `skills/<name>/`, published by the
marketplace in `.claude-plugin/`. A skill file is a document for an agent; write it in the skill
shape and test every script change first.

- [docs/development.md](docs/development.md): read before adding or changing a skill, a script or
  the manifests. It has the skill shape, the checks and the version bump.
- [CONTRIBUTING.md](CONTRIBUTING.md): read before a commit or a pull request. It has the branch
  names and the commit scopes.
